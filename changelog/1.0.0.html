DataFusion Comet 1.0.0 Changelog#

This release consists of 244 commits from 23 contributors. See credits at the end of this changelog for more information.

Fixed bugs:

  • fix: decline native V1 scans on object_store-unsupported filesystem schemes #4525 (schenksj)

  • fix: exclude release scratch dirs from RAT and license skill docs #4685 (andygrove)

  • fix: correct stale unix_timestamp NTZ and date_format codegen-default doc text (#4502) #4645 (andygrove)

  • fix: fall back for decimal SUM/AVG over sliding window frames (window audit) #4732 (andygrove)

  • fix: date_trunc schema mismatch and DST handling in non-UTC timezones #4761 (andygrove)

  • fix: size Iceberg delete files in the native scan to avoid dropping deletes #4760 (mbutrovich)

  • fix: gate non-default collations for Spark 4 datetime expressions #4693 (0lai0)

  • fix: ArrayInsert evaluation for null source arrays #4726 (peterxcli)

  • fix: array expression audit follow-ups (#4503) #4713 (andygrove)

  • fix: report FromUnixTime non-default format as Unsupported #4847 (andygrove)

  • fix: emit JDK libjvm search path from core build script to fix -ljvm CI link failures #4868 (andygrove)

  • fix: work around DataFusion 54.1.0 Parquet page-index regression #5132 (mbutrovich)

  • fix: throw ARITHMETIC_OVERFLOW for Long.MinValue div -1 under ANSI mode #5084 (andygrove)

  • fix: seed native Parquet scan reader options from session config #5107 (mbutrovich)

  • fix: raise REMAINDER_BY_ZERO for Float/Double under ANSI mode #5081 (andygrove)

  • fix: reduce log verbosity at per-task logging callsites #5155 (mbutrovich)

  • fix: round on Int64 with scale <= -19 now overflows correctly #5082 (andygrove)

  • fix: match Spark’s whitespace trim semantics for casts from string to boolean, integral, float/double and decimal #5150 (andygrove)

  • fix: count ReusedSubquery and CometSubqueryBroadcast correctly in extended explain #5206 (andygrove)
