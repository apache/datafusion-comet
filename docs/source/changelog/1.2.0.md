# DataFusion Comet 1.2.0 Changelog (Unreleased)

## Behaviour Changes

Native integral `sequence` now has a per-invocation output byte ceiling, derived from the configured
memory pool and task slots by default in off-heap mode. Valid queries that exceed it can fail before
output allocation. Set `spark.comet.legacy.allowUnboundedSequence=true` to restore the previous
absence of this byte ceiling, even when `spark.comet.exec.sequence.maxBytesPerInvocation` is
explicitly set. The legacy flag defaults to `false` and is deprecated; existing per-row and batch
element limits remain in effect. See the
[Upgrade Guide](../user-guide/latest/migration-guide.md#native-integral-sequence-byte-ceiling) for
scope and tuning options.
